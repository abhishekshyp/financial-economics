First principles · The allocation problem02

An asset is not risky in isolation — it is risky by its contribution

The investor's problem: split wealth across N assets to get the most return per unit of risk. Before 1952, diversification was folk wisdom — don't put all eggs in one basket — with no theory for how to combine assets.

Harry Markowitz's insight (his doctoral work at Chicago, published in the Journal of Finance) was to judge each security not by its own variance but by how it moves with the rest of the portfolio. Portfolio risk is driven by covariances, not the individual variances alone.

The cross-term is the whole game: when ρ < 1, combining assets destroys risk without destroying return.
Why the average of risks is the wrong sum
Two-asset variance σ2p = w2σ2A + (1−w)2σ2B
        + 2 w(1−w)ρ σAσB

The bold cross-term shrinks as ρ falls. For an equal-weight book of N assets,

σ2p = (1/N) σ̄2 + (1−1/N) cov̄

As N → ∞, own-variance vanishes and portfolio risk converges to the average covariance — the irreducible, systematic floor. Idiosyncratic risk is free to diversify away; co-movement is not.

Model · Mean–variance optimisation03

The framework, in matrix form

Inputs & the program
Estimated from data μ  (N×1 expected returns)
Σ  (N×N covariance matrix)
Portfolio moments μp = wTμ    σ2p = wTΣw
The quadratic program (QP) minw  ½ wTΣw
s.t.  wTμ = μ*  (target)
      wT1 = 1  (fully invested)

Add w ≥ 0 and the clean closed form breaks — that is exactly where Solver enters (slide 05).

With only the two equality constraints, the Lagrangian L = ½wTΣw − λ(wTμ−μ*) − γ(wT1−1) has first-order condition Σw = λμ + γ1, so the optimum is w* = Σ−1(λμ + γ1). Solving the two constraints for λ, γ gives the whole frontier in closed form.

Frontier scalars (Merton, 1972) a = μTΣ−1μ   b = μTΣ−11
c = 1TΣ−11   d = ac − b2
Frontier equation — a parabola in variance σ2p = (c μ2p − 2b μp + a) / d

The global minimum-variance portfolio (GMV): wgmv = Σ−11 / c, with μgmv = b/c and σ2gmv = 1/c.

Interactive · Diversification benefit04

The frontier bows left as correlation falls

The efficient frontier is the upper edge of the feasible set: for every level of risk it gives the highest attainable return. Anything below the GMV (the leftmost point) is dominated — same risk, less return — and no rational mean-variance investor holds it.

Two assets: Equity (μ=12%, σ=20%) and Bonds (μ=5%, σ=8%). Drag ρ and watch the curve — lower correlation carves out risk you were not compensated for.

The core distinction05

Analytic Markowitz vs the Excel Solver route

These are not rival theories. Markowitz is the model — the QP. Solver is a numerical method for solving that same QP when real-world constraints break the closed form.

Analytic Markowitz Excel Solver
Method Matrix algebra — invert Σ, closed form Iterative numerical search (GRG Nonlinear)
Short sales Unbounded w allowed by default Add w ≥ 0, box & group limits trivially
Constraints Only equalities stay closed-form Handles inequalities naturally (KKT)
Output Whole frontier in one parametric sweep One optimal point per run
Accuracy Exact (up to matrix conditioning) Tolerance-based; local optima if non-convex
Best for Theory, intuition, unconstrained frontier Realistic mandates with live constraints
The Solver model, mapped to the QP
Changing cells  (the decision) weights  w1..N
Objective → Min =MMULT(TRANSPOSE(w),MMULT(Σ,w))
(portfolio variance wTΣw)
Constraints SUM(w) = 1
wTμ = target  // vary to trace frontier
w ≥ 0  // optional: no shorting

Engine: GRG Nonlinear — the variance objective is convex, so the QP has a unique global optimum. Re-run across targets and you have rebuilt the frontier numerically.
