Method & assumptions

Validation

A submission is valid only if it holds exactly 25 stocks with a weight and its weights sum to 100% after rounding to zero decimals (round(Σwᵢ) = 100). Anything else — over- or under-count, or an off-100 sum — is excluded, and its reason is reported before scoring proceeds. Weights are read as percentages.

Returns & covariance (computed once, on all stocks)

Daily simple returns from the price levels: rᵢ,ₜ = Pᵢ,ₜ / Pᵢ,ₜ₋₁ − 1 The full sample covariance matrix Σ of daily returns is built once across every stock in the price file (sample estimator, ddof = 1), then each fund reuses the relevant block. This avoids recomputing covariances per student.

Fund value — buy-and-hold from ₹1 crore

On day 1 each weight buys a fixed share count that is then held; the portfolio value drifts with prices (no rebalancing, no cash, no leverage — the realistic "deploy the capital" case): shareᵢ = wᵢ · 1cr / Pᵢ,₁  →  Vₜ = Σᵢ shareᵢ · Pᵢ,ₜ

Reported metrics (2 d.p.)

Absolute return = V_last / 1cr − 1.   CAGR = (V_last / 1cr)^(1/years) − 1, with years = (last date − first date) / 365.25 (calendar basis).   Annualised risk is the ex-ante portfolio volatility from the chosen weights: σₐ = √(wᵀ Σ w) · √252 Reward per unit of risk = CAGR / σₐ. This mirrors the assignment's return/risk objective; it is a growth-to-volatility ratio, not a Sharpe ratio (no risk-free rate is subtracted).

Notes

The value path uses realised buy-and-hold drift while risk uses the fixed target weights, so the ratio pairs a realised return with an ex-ante risk — standard for scoring a designed portfolio. Ranking is by final value, per the brief; the CAGR/σ column exposes the risk-adjusted ordering, which can differ.
