Case study · IITR Startup AIF02

Did the IITR AIF create value?

You manage the IITR Startup AIF, investing in startups emerging from the IIT Roorkee ecosystem. After five years, the Investment Committee asks you to present the fund's performance.

BenchmarkNifty Next 50.

Investment Committee: "Did our AIF actually outperform the Nifty Next 50 over these five years?"

The cash flows are dated and unequal, and the question is benchmark-relative. Answering it draws on several of the measures that follow: XIRR for the fund's own return, TWRR for a like-for-like comparison with the index, and active return against the Nifty Next 50.

01 · Absolute return (HPR)03

Absolute return, the total change

The holding-period return: end value against start value, including any distributions received.

R = (Vend − Vbegin + D) / Vbegin

BiasIt is not normalised for time, so 40% earned over one year and 40% over eight years read as equal. It uses only the start and end values plus distributions, ignoring the path and the timing of any cash flow in between.

Mental model. Total distance on an odometer. It records how far the money travelled, not how long the trip took.
Same absolute return, different clock

Hold ₹100 that grows to ₹160. The absolute return is fixed at 60%. Change only the holding period and read the annualised equivalent.

60%
Annualised equivalent
9.86%
02 · CAGR04

CAGR, one smoothed annual rate

The constant annual rate that carries the start value to the end value over n years.

CAGR = (Vend / Vbegin)1/n − 1

BiasEndpoint dependence. CAGR reads only the first and last value, so two portfolios with the same endpoints but very different journeys report the identical number. It presents growth as smooth, hides interim volatility and drawdowns, and shifts with the chosen start and end dates.

Mental model. Average speed, total distance over total time. It says nothing about the stops and the accelerations along the way.
Two paths, same endpoints, same CAGR

Both paths run ₹100 to ₹200 over 5 years. Increase the deviation and the CAGR does not move, even as the path volatility rises.

CAGR
14.87%
Path volatility
18%
03 · XIRR (money-weighted)05

XIRR, the rate on dated cash flows

The rate that discounts every dated cash flow to a net present value of zero. It is the money-weighted return.

Σk CFk / (1 + r)(dk − d0)/365 = 0

BiasMoney-weighted, so the size and timing of contributions drive the result. It reports the investor's own experience rather than the strategy. It assumes interim flows are reinvested at r, can have multiple or no real roots when flow signs alternate, and needs a numerical solver.

Mental model. The interest rate a bank account would have to pay to reproduce your exact dated deposits and withdrawals.
A 12-month SIP of ₹10,000

₹10,000 invested on the first of each month, ₹1,20,000 in total. Set the year-end value and read the money-weighted XIRR against the plain absolute return.

13.97%
Absolute return

04 · TWRR (time-weighted)06

TWRR, cash-flow timing removed

Chain the return of each sub-period between external cash flows. The deposits and withdrawals cancel out.

1 + TWRR = ∏i (1 + ri)

BiasIt requires valuing the portfolio at every cash-flow date, which is data-intensive. By design it removes the effect of the investor's timing, so it does not equal the rupee return the investor actually earned and can diverge from XIRR. Each sub-period is weighted equally regardless of the capital deployed in it.

Mental model. How one rupee left fully invested from the start would have grown. It measures the strategy, not the investor, and is the fund-comparison standard (GIPS, SEBI).
Same fund path, TWRR against XIRR

Fund falls 10% in the first half, rises 25% in the second, so TWRR is fixed. Move ₹1,20,000 between an early and a mid-year entry and watch only the money-weighted number react.

TWRR (strategy)
12.50%
XIRR (investor)
25.48%
05 · Rolling returns07

Rolling returns, every start date

The annualised return over every window of length k that slides through the history, reported as a distribution.

Rt = (Vt+k / Vt)1/k − 1  for all t

BiasOverlapping windows share data, so the observations are autocorrelated rather than independent, and their standard errors are understated. Results depend on the length of available history and on the chosen window and step. Each window is itself a CAGR, so it inherits within-window smoothing.

Mental model. Not one lucky start date, but the full set of outcomes an investor entering on every date would have seen.
NIFTY 50 rolling return by start year

06 · Active return08

Active return, the margin over the benchmark

The portfolio return against the return of its benchmark over the same period.

Ractive = Rp − Rb  (geometric: (1+Rp)/(1+Rb) − 1)

BiasIt depends entirely on the choice of benchmark, and a mismatched benchmark makes the number meaningless. It carries no adjustment for the risk taken to earn it, so a positive figure can come from higher beta or leverage rather than selection. Simple subtraction is only approximate once returns compound over several periods.

Mental model. The scoreboard margin against the index, read before any risk adjustment.
Worked figures
Portfolio return Rp14.00%
Benchmark Rb (NIFTY 50 TRI)12.86%
Active return (arithmetic)+1.14%
Active return (geometric)+1.01%

The arithmetic and geometric figures separate as the horizon lengthens, since the geometric form compounds the ratio of the two return streams.

07 · Excess return09

Excess return, the reward over cash

The portfolio return above the risk-free rate. This is the quantity that feeds the Sharpe ratio and the CAPM regression.

Rexcess = Rp − Rf

BiasThe term is ambiguous, since excess can also mean over a benchmark, so the reference has to be stated. The value depends on the risk-free proxy chosen, such as the bill tenor and the currency. It is a raw difference and carries no adjustment for the risk taken.

Mental model. The reward for taking any risk at all, above parking the money in the safest asset.
The two differences, side by side
Portfolio return Rp14.00%
Risk-free Rf (T-bill)6.50%
Excess over risk-free+7.50%
Excess over benchmark (item 6)+1.14%

Excess over risk-free isolates the reward for bearing risk. Excess over a benchmark isolates the margin against a peer index. Both are called excess return in practice.

08 · Risk-adjusted return (Sharpe)10

Sharpe, excess return per unit of total risk

The excess return over the risk-free rate, divided by the standard deviation of returns.

S = (Rp − Rf) / σp

BiasIt uses total volatility, which penalises upside and downside symmetrically, so it fits skewed or option-like returns poorly. It relies on mean and variance describing the distribution, ignoring skewness and fat tails. Annualising by the square root of the number of periods assumes returns are independent over time. Stale pricing in illiquid assets lowers measured σ and raises the ratio.

Mental model. Return earned per unit of total volatility, measured against cash. Its original name was the reward-to-variability ratio.
Sharpe of a 14% return, σ of 15%

The numerator is the excess return from item 7. Move the risk-free rate and read how the ratio responds.

Excess return
7.50%
Sharpe ratio
0.50
09 · Required return (CAPM)11

CAPM, the required return, a hurdle

The return an asset should offer for its systematic risk. This is an expected return set before investing, not a realised one.

E(Ri) = Rf + βi(E(Rm) − Rf)

BiasIt is single-factor, pricing only market risk, while size, value, and momentum factors explain part of returns it misses (Fama and French). It rests on assumptions such as homogeneous expectations, frictionless markets, and one period. Beta is estimated with error and drifts, and the true market portfolio is unobservable (Roll's critique).

Mental model. The minimum return the asset must offer to justify its market risk, a rent for bearing systematic risk.

Rf 6.5%, market premium 6.0%. Move beta to read the required return.

10 · Alpha return12

Alpha, active return after market risk

The return above what CAPM predicts for the portfolio's beta.

α = Rp − [ Rf + βp(Rm − Rf) ]

BiasIt is model-dependent. It assumes CAPM is the correct return model, so exposure to factors outside the model, such as size, value, or momentum, is recorded as alpha. It inherits the beta estimate's sensitivity to the window, the frequency, and the benchmark, and it assumes beta is stable.

Mental model. The part of the return market exposure cannot account for. Active return (item 6) measures the margin; alpha measures the margin after paying for market risk.
Alpha from the same portfolio
Portfolio return Rp14.00%
Risk-free Rf6.50%
Market Rm (NIFTY 50 TRI)12.86%
Beta β0.90
CAPM-predicted return12.22%
Alpha+1.78%

Active return here is +1.14%, alpha is +1.78%. They differ because beta of 0.90 lowers the risk-based hurdle below the benchmark.

Reference · matching the measure to the case13

Which return, which situation

SituationReturn measure
Lumpsum, buy and hold, total growthAbsolute return
Lumpsum, buy and hold, annualisedCAGR
SIP or irregular contributions, the investor's own returnXIRR (money-weighted)
Comparing funds or managers, independent of investor flowsTWRR (time-weighted)
Consistency across entry dates and horizon dependenceRolling returns
Performance against a benchmark indexActive return
Reward above the risk-free rate (input to Sharpe, CAPM)Excess return
Return per unit of total riskSharpe ratio
Setting a hurdle or expected return before investingCAPM required return
Performance against the benchmark after market riskAlpha

The SIP against lumpsum split is the common one. A mutual fund SIP is read with XIRR because the contributions are dated and unequal. The scheme itself is compared using TWRR, which strips those contributions out. A single lumpsum held to a date is read with CAGR, since there is only one inflow and one endpoint.
